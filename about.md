# Practice+

**Practice+** is a Geometry Dash mod that aims to make Practice Mode more convenient, flexible, and useful for improving your skills.

## Features

- **Checkpoint Controls** — Navigate between saved checkpoints.
- **Quick Checkpoint Saving** — Save a checkpoint while playing.
- **Automatic Checkpoints** — Automatically create checkpoints at configurable progress intervals.
- **Practice Statistics** — Track deaths and best progress during a run.
- **Quick Restart** — Restart your practice run quickly.
- **Customizable Settings** — Enable or disable features to suit your playstyle.
